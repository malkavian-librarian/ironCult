# [MR] Motorcycle Meetup & Event Discovery — Market Research

## 1. Idea Summary

* **Description:** Location-based motorcycle event discovery: "events within 100km this weekend." Includes rallies, track days, group rides, bike nights, swap meets. Add to calendar, get directions.
* **Target:** Motorcycle riders looking for events and meetups
* **Category:** Event discovery platform

## 2. Market Sizing (TAM/SAM/SOM)

**TAM:** Global motorcycle market: ~$142B (2025), CAGR ~3% (Mordor Intelligence)

* Motorcycle event discovery subset: ~$20M-$50M (niche segment)
* Adjacent: event ticketing market $70B+ (Eventbrite, etc.)
* Motorcycle-specific events: ~1-2% of riders use dedicated event platforms = ~$20M TAM

**SAM:** ~$15M (US + EU motorcycle event discovery)

**SOM:** ~$1M Year 1 (freemium + commission on paid event tickets)

## 3. Competitive Analysis

| Competitor | Features | Pricing | Weaknesses |
| -- | -- | -- | -- |
| MOTOSPOT | Community + event discovery | Free + IAP | Small user base |
| TONIT | Community + events + ride tracking | Free + IAP | Limited event search |
| CycleFish | Event calendar, rallies | Free for users | Outdated, US-only |
| Eventbrite | General event ticketing | Transaction fees | Not motorcycle-specific |
| Calimoto | Navigation + some events | Freemium | Events are secondary feature |
| Facebook Events | General events | Free | Not motorcycle-filtered, noisy |

## 4. Market Gap

Finding motorcycle events requires checking multiple forums, Facebook groups, and local websites. No centralized, location-aware motorcycle event calendar exists with filtering by event type and distance.

## 5. Reddit VoC

* Difficulty finding local events without checking multiple forums
* Lack of centralized platforms for event discovery
* Desire for real-time updates and notifications
